\# 🚀 Blog Backend API



A robust and secure RESTful API backend for a blogging application, built with \*\*Java\*\*, \*\*Spring Boot\*\*, and \*\*Spring Security\*\*, integrated with a database and containerized using Docker.



\## 🛠️ Tech Stack \& Tools

\* \*\*Language:\*\* Java 17+

\* \*\*Framework:\*\* Spring Boot, Spring Data JPA, Spring Security

\* \*\*Database:\*\* MySQL / PostgreSQL

\* \*\*Authentication:\*\* JWT (JSON Web Token)

\* \*\*API Documentation:\*\* Swagger UI / OpenAPI

\* \*\*Containerization:\*\* Docker

\* \*\*Build Tool:\*\* Maven



\## ✨ Core Features

\* \*\*Authentication \& Authorization:\*\* Secure User Registration and Login using JWT and Spring Security.

\* \*\*Post Management:\*\* Create, Read, Update, and Delete (CRUD) blog posts.

\* \*\*Comment System:\*\* Add, manage, and interact with comments on posts.

\* \*\*File Uploads:\*\* Support for media and image attachments handling.

\* \*\*Exception Handling:\*\* Global exception handling for clean, descriptive error responses.
